Version 0.01

Manhwa Archive version history starts here. Every official release increases the version by 0.01.

  • Merge the full Gothic Archive experience, details/gallery workflows, expanded tracker, themes, achievements, collections, statistics, and responsive navigation.
  • Include Smart Integrations: public AniList metadata search with review-before-import, loaded-catalogue health checks, progress helpers, and a browser-local action log.
